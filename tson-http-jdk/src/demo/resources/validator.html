TSON validator — the Java implementation, over HTTP

A schema and a document go to POST /validate as a TSON document, and every problem comes back in one pass. The same pair on tson.io is checked by the TypeScript implementation in your browser; this one is checked by the Java implementation on the server, so the two verdicts can be compared. A difference in code, message or source position between them is a finding.
